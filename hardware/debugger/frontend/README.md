# Aldebaran Debugger UI

This is the UI for the debugger. For more details, how to use it, see [How to use the debugger?](../../../docs/how-to-use-the-debugger.md)


## How to install?

```
npm install
```


## How to run?

```
npm run dev
```

This will start the dev server at http://localhost:5173/

(And also proxy the backend (the debugger) to port 5173, so the UI can access the backend without CORS.)
